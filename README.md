# Rukcord

Discord mod for iOS.
This build targets Discord 350.0 and requires iOS 16 or newer.

- Rootless deb for Dopamine.
- IPA for sideloading, built from your decrypted Discord app.
- Plugins, themes, fonts and developer tools in Discord Settings.

Font changes require closing and reopening Discord.
The IPA needs signing and provisioning by your installer. Push notifications
are not provisioned by this build. Other Discord releases are untested.
